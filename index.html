How it works

  1. Open an Actor on Apify Store and fill in the form, or send the example request from its page.
  2. The Actor reads the official source live and checks every record against your filters.
  3. Download JSON, CSV or Excel, or schedule the run and push results to your tools.

What every datagrit Actor guarantees

  • Truthful output. Documented fields, empty values instead of guesses, and a run status that says how much of the source carried each key field.
  • Fair billing. No charge for duplicates, empty results or the status row.
  • Loud failures. If a source changes and stops publishing a field, the run fails instead of quietly returning nothing.
  • Public sources only. No logins, no personal accounts, polite request rates.

Questions

What is an Apify Actor?

A small cloud program on the Apify platform. You fill in a form or send one API request, it collects the data and gives you a clean dataset you can download as JSON, CSV or Excel.

How much does it cost?

Each Actor charges a small fee per run and a price per result, so you pay for the records you receive. Prices per result are lower on paid Apify plans, and the Apify free plan includes monthly credit to try any Actor.

Where does the data come from?

From official public sources such as procurement portals, company registers and public job boards. Each Actor page names its source and what it does and does not cover.

Can I run them on a schedule or from my code?

Yes. Use Apify schedules for daily or weekly feeds, or call any Actor from cURL, Node.js or Python with the examples on its page.
