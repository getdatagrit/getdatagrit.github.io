GLEIF LEI Lookup reads the Global Legal Entity Identifier database and returns each legal entity together with who owns it. Give it LEI codes or company names and you get the registration data, address, status and renewal dates, plus the direct and ultimate parent in the same row. When an entity reports no parent, you get the reason it gave instead, such as no known person or natural persons. You can also list the direct subsidiaries of any entity. Export the data as JSON, CSV or Excel, call it through the Apify API, or plug it into n8n, Make and AI agents through MCP. The first 10 results of every run are free.

Who is it for?

  • KYB and compliance teams mapping the accounting-consolidation parents of a counterparty and documenting why a parent is missing.
  • Banks, brokers and fintechs enriching customer files with an LEI, legal address, registration authority and renewal date.
  • Risk and procurement analysts finding subsidiaries of a group under one parent.
  • Data teams cleaning company names against the official LEI register.

How to use it

  1. Enter LEI codes (20 characters) for exact lookups, or company names for a full-text search. Names return the number of matches you set.
  2. Keep Include parents on to add the direct and ultimate parent, or the reporting exception.
  3. Switch on Include direct subsidiaries and set a limit to list the subsidiaries of each entity as separate rows.
  4. Set the maximum number of results and run the Actor.

GLEIF allows roughly 60 requests per minute per IP address, and the Actor stays under that limit. An entity with parents needs three to five requests: one for the record, one for each parent, and one more for each parent that is not reported, to read the reason. With the limit that is about 3.5 to 6 seconds per entity, plus about 1.1 seconds per 200 subsidiaries.

What data do you get?

Each record contains the LEI, legal name and other names, jurisdiction, category, status, legal form code, business register and registration number, creation date, legal address with city, region and country, headquarters city and country, the LEI registration status with initial registration, last update and next renewal dates, the managing operating unit, the corroboration level, BIC codes, the direct and ultimate parent with LEI and name, the exception reason when no parent is reported, and the total number of direct subsidiaries. Subsidiary rows carry a relation flag and the LEI of the parent they belong to.

A parent shown as empty with an exception reason is a legitimate answer: it means the entity reported that it has no consolidating parent, not that data is missing. NOT_REPORTED means the entity has neither reported a parent nor given a reason.

Is it legal to scrape this data?

The Actor reads only the open data that GLEIF publishes through its public API for free use. It does not log in or bypass access controls. Entities that are sole proprietors can include personal data in the record, so you are responsible for handling the output in line with applicable data protection law. This description is not legal advice.

Input

FieldNameTypeWhat it does
entities requiredLEI codes or company namesarrayEach entry is either a 20-character LEI code (exact lookup) or a company name (full-text search in the GLEIF database). Names return up to the number of matches set below.
includeParentsInclude parentsbooleanAdds the direct and ultimate parent of each entity. When no parent is reported, the reason given by the entity is returned instead, for example NO_KNOWN_PERSON, NATURAL_PERSONS or NON_CONSOLIDATING. Costs two to four extra API calls per entity (one per parent, plus one per missing parent to read the reason), so runs with many entities are slower.
includeChildrenInclude direct subsidiariesbooleanAdds the direct subsidiaries of each entity as separate rows, up to the limit below.
maxChildrenPerEntityMaximum subsidiaries per entityintegerUpper limit of direct subsidiaries returned for each entity. The total number of subsidiaries is always reported on the parent row.
maxMatchesPerNameMaximum matches per company nameintegerHow many search results to return for each company name. Ignored for LEI codes.
maxItemsMaximum resultsintegerStop after this many rows in total. The first 10 results of every run are free.
proxyConfigurationProxy configurationobjectOptional proxy. Leave disabled: the GLEIF API is public and needs none. GLEIF limits requests to about 60 per minute per IP address, and the Actor stays under that limit.

Frequently asked questions

What is an LEI?

A 20-character code that identifies a legal entity in financial transactions and is maintained in a public database.

Why is the parent empty?

Either the entity reports no consolidating parent, in which case the exception reason is filled in, or nothing is reported at all.

Does it cover every company?

Only entities that hold an LEI. Many small companies do not.

How fresh is the data?

Every run reads the live GLEIF database.

Something looks wrong.

Open an issue with the input you used; changes at the source are fixed quickly.
