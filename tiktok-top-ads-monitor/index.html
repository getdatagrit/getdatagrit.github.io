TikTok Top Ads Monitor reads the public TikTok Creative Center Top Ads ranking for the countries, industries and campaign objectives you choose and returns every ad as one clean row: title, brand, industry, objective, likes, CTR, video and cover links, and, when you ask for details, the landing page, comments, shares and the countries the ad ran in. No login and no cookies are needed. Turn on Only new ads and schedule the Actor, and each run returns just the ads that entered your ranking since the last run, so a daily run is a feed of fresh winning creatives instead of the same top 20 again.

Why use this Actor?

  • Creative research for ecommerce and DTC brands: see which ads TikTok ranks highest in your industry this week, with the landing page behind each one.
  • Competitor and market watching: schedule a daily run for your industry and objective and get only the ads that are new.
  • Agencies and media buyers: build swipe files and weekly reports from several countries in one run.
  • Dropshipping and product research: new top ads in Household Products, Beauty or Tech are an early signal of products that are being pushed.
  • Data pipelines and AI agents: typed output with a description of every field, ready for n8n, Make, Zapier, Google Sheets or MCP.

What is different here?

One run reads the whole combination of countries, industries, objectives, languages and sort orders, merges an ad found in several lists into one row and tells you its best rank and every list it appeared in. Every row carries isNew, firstSeenAt and timesSeen, kept per set of filters, so two monitors never hide each other's ads. Ad details are included in the one ad price.

Limits you should know

Creative Center shows anonymous visitors one page of 20 ads per list, so a single list never returns more than 20 ads. To see more of the ranking, add sort orders, industries, objectives or countries: the Actor reads them all and merges the results. Keyword search is not available because the anonymous Creative Center API returns no results for it. The video and cover links are signed by TikTok and expire after a few days, so download the files if you need to keep them. The status message of every run states how many ads were read, how many had an industry and how many details were fetched, and the run fails instead of returning silent zeros when TikTok changes its response.

Is it legal to scrape TikTok Creative Center?

The Actor reads only the public Top Ads pages that anyone can open without an account, and returns advertising metrics and links, not personal profiles. You are responsible for how you use the data and for following TikTok's terms and the laws that apply to you.

Call it from your code

Run the Actor and get the results in one request. Replace YOUR_APIFY_TOKEN with the token from your Apify account settings.

curl -X POST "https://api.apify.com/v2/acts/datagrit~tiktok-top-ads-monitor/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"countries":["US","GB"],"sortBy":["for_you","ctr"],"periodDays":"7","includeDetails":true,"maxItems":50}'
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('datagrit/tiktok-top-ads-monitor').call({
  "countries": [
    "US",
    "GB"
  ],
  "sortBy": [
    "for_you",
    "ctr"
  ],
  "periodDays": "7",
  "includeDetails": true,
  "maxItems": 50
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items.length, items[0]);
